# LIGHTSHIFT — City of Light

An original, offline-first, bilingual Arabic/English 5×5 tile-rotation puzzle game.

**Status:** v0.2 experimental PWA. This repository contains source code, automated tests and GitHub Pages deployment.

**Quick start:** `npm test` and `npm run build`, or serve the project directory through a local HTTP server.

See `README_AR.md` for Arabic documentation. MIT License.
