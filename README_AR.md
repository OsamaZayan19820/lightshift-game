# LIGHTSHIFT — City of Light, Difficulty Pilot v0.3

## لماذا تغيرت آلية اللعب؟
النسخة v0.2 كانت تكتفي بإضاءة المنازل وتسمح بالقفز إلى المستوى العاشر، دون قياس تدرج الصعوبة.

## آلية التحدي الجديدة
- لكل مرحلة شبكة 3x3 إلى 6x6، ويجب تغذية **كل** قطع الشبكة وربط **جميع** المنافذ دون نهايات مكشوفة.
- المستويات تفتح تباعًا بعد الإنجاز. يبدأ هذا الإصدار بتقدم جديد مع الاحتفاظ ببيانات v0.2 منفصلة محليًا.
- لكل مرحلة مسار حل مؤكد مبني على شجرة توصيل صحيحة.
- معيار الجهد المرجعي: عدد دورات 90 درجة باتجاه عقارب الساعة لإرجاع القطع إلى الحل المرجعي. يتزايد من 7 إلى 66، لكنه **ليس إثباتًا للحد الأدنى العالمي للحركات**؛ قد توجد حلول بديلة أسهل.
- حد تلميحين لكل مرحلة. النتيجة 3 نجوم مرتبطة بحركات الحل المرجعي وعدم استخدام التلميحات.

## التدقيق
`npm test` ثم `npm run build`. الاختبارات تمنع القفز للمستوى العاشر، وتفحص اتصال كل القطع وسلامة الحدود وتزايد جهد الحل المرجعي.
تم أيضًا اختبار DOM لمحاكاة شاشة 390px باستخدام Chromium، بما في ذلك الفصل الأول، القفل، التراجع، الفوز، وفتح المرحلة التالية. **لم يتم الاختبار على iPhone فعلي**.

## المخاطر المتبقية
لم يثبت هذا القياس أن جهد الحل الأدنى يتزايد، كما لم يخضع المنتج لاختبار مستخدمين متعددين. يجب اختبار الصعوبة الحقيقية وزمن إنهاء كل مرحلة قبل إطلاق الإنتاج.
