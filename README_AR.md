# LIGHTSHIFT — City of Light · MVP v0.2

## الحالة
نواة PWA محسّنة محلية مجانية وقابلة للاختبار، وليست تطبيقًا منشورًا أو معتمدًا من Google Play / App Store.

## ما هو المنجز؟
- تصحيح اتجاه شبكة اللعبة في الواجهة العربية حتى تتطابق التوصيلات والجهات الفعلية.
- مساعدة داخل اللعبة واستئناف تقدم المستوى عند إعادة فتح الصفحة.
- تحديث خدمة العمل دون اتصال لاستقبال صفحة أحدث عند وجود شبكة.
- عشرة مستويات مُولَّدة حتميًا ومضمونة وجود حالة حل لكل منها.
- تدوير مسارات 90° واتصال كهربائي فعلي على شبكة 5×5.
- كشف فوز مبني على اتصال كل منزل بالمحطة، لا على مؤثر بصري مزيف.
- تراجع وإعادة وتجربة تلميحات ومستوى تختاره مباشرة.
- واجهة عربية/إنجليزية، تخزين محلي لأفضل نتيجة، وضع PWA دون خادم خلفي.
- بلا إعلانات أو حسابات أو APIs أو مكتبات خارجية.

## تجربة محلية (كمبيوتر)
يتطلب Python مثبتًا؛ من داخل مجلد المشروع:
```bash
python -m http.server 8000
```
ثم افتح http://localhost:8000

## اختبارات محرك اللعب
يتطلب Node.js:
```bash
npm test
```
تعتمد الاختبارات على node:test دون تثبيت أي حزم خارجية.

## نشر مجاني على GitHub Pages (بعد قرار بالنشر)
1. افتح مستودع GitHub عامًا جديدًا خاصًا باللعبة فقط. لا ترفع أسرارًا أو بيانات خاصة.
2. ارفع جميع الملفات من جذر هذا المشروع، بما فيها index.html وengine.mjs وsw.js وicons.
3. من Settings → Pages، ضمن **Build and deployment** اختر **Source: GitHub Actions** (لا تختر Deploy from a branch)، ثم احفظ الإعداد.
4. بعد تفعيل Pages شغّل workflow من تبويب Actions → Test and deploy LIGHTSHIFT → Run workflow، ثم افتح الرابط المنشور على هاتف iPhone في Safari ثم Share → Add to Home Screen؛ على Android استخدم خيارات التثبيت من المتصفح المدعوم.
5. تأكد من أن الرابط يعمل عبر HTTPS وأن اللعبة تعمل دون اتصال بعد زيارتها وتحميل ملفاتها مرة واحدة.

تنبيه: GitHub Pages بالخطة المجانية يتطلب مستودعًا عامًا وقد يكشف شفرة اللعبة للجمهور. لتبقي الشفرة خاصة استخدم استضافة مناسبة بعد مراجعة شروطها.

## تحويلها لاحقًا لتطبيقين أصليين
- Capacitor المفتوح المصدر يوفّر مشروع Android وiOS من أصول HTML/CSS/JS بعد الاختبار.
- Android: Android Studio → توقيع نسخة release → توليد Android App Bundle (.aab) → Google Play Console.
- iOS: يلزم macOS وXcode للتجميع والتوقيع؛ وحساب Apple Developer مدفوع للنشر العادي.
- رسوم المتجرين لا تدخل في تكلفة بناء هذه النسخة: Google Play 25 USD لمرة واحدة؛ Apple 99 USD سنويًا عادة.
- قبول التطبيقات يخضع لمراجعات المتاجر وشروطها الحالية.

## الحدود / الملاحظات
- لا توجد إحصاءات استخدام؛ تقييم الرغبة في العودة يحتاج اختبارًا خارجيًا وموافقة اللاعبين.
- لا توجد مستويات تُولد على خادم؛ جميع المراحل ثابتة بذورًا محلية ويمكن إرجاعها.
- لا توجد leaderboard أو multiplayer أو مشتريات داخل التطبيق.
- درجة النجوم مقارنة بحل مرجعي، وليست إثباتًا للخوارزمية الرياضية المثلى.
- `localStorage` قابل للحذف وقد لا يتزامن بين الأجهزة.
- الاختبار التلقائي يغطي محرك اللعبة فقط ولا يثبت القبول على متاجر الهاتف.

## ملكية وتنفيذ
المشروع نموذج أولي قابل للمراجعة؛ لا يتم النشر أو إنشاء مستودع أو الدفع دون موافقة المستخدم.

## دليل إنشاء المستودع لمرة واحدة
1. تأكد من أنك متصل بحساب GitHub الصحيح.
2. أنشئ مستودعًا **جديدًا** باسم `lightshift-game`؛ لا تستخدم مستودعات مشاريع أخرى.
3. اترك إعداد الملفات الأولية اختياريًا (يمكن استخدام مستودع فارغ).
4. شارك رابط المستودع فقط، وليس كلمة مرور أو مفتاح وصول.
5. يمكن رفع محتويات هذا المجلد من خلال اتصال GitHub المخوّل ثم تفعيل Pages من إعدادات المستودع.
6. يبقى نشر التطبيق في Google Play / App Store مرحلة منفصلة برسوم المطور وشروط المراجعة.

## نطاق الثقة والاختبار
اختبارات Node.js تثبت سلامة محرك الألغاز الأساسي فقط. اختبار متصفح هاتف حقيقي، دعم التثبيت، وضع عدم الاتصال، وإجازة المستخدم للنشر العام ما زالت بوابات مستقلة.

## النشر الآلي بعد رفع المستودع
يحتوي المشروع على `.github/workflows/pages.yml`. عند رفعه إلى الفرع `main` في مستودع خاص باللعبة، وفي إعدادات Settings → Pages اختر **Build and deployment → GitHub Actions**. ينفذ workflow اختبار محرك اللعبة أولًا، ثم ينشر الأصول اللازمة فقط من `dist/`؛ ولا ينشر كود الاختبارات أو ملفات الوثائق.

تفعيل GitHub Pages خارجيًا لم يحدث بعد؛ لا تدّعِ أن الموقع متاح حتى يصبح الرابط بحالة نجاح في Actions وPages. إعدادات الحساب أو قيوده قد تتطلب تدخلاً يدويًا.
